# belstu-notifier
Скрипт для оповещения о новых лабораторных на https://diskstation.belstu.by:5001 \
Он опрашивает каждые 5 минут папки с лабами, и если находит таковые, отсылать уведомление и сам файл лабы 

## Как пользоваться
Для того чтобы пользоваться скриптом, надо создать .env файл
BASE_URL - целевой сайт (это может быть любая NAS от Synology, чем и является дискстейшен)
USR - логин (например student)
PASSWORD - пароль (кто знает, тот знает)
BOT_TOKEN - бот в которого вы хотите отправлять оповещения
CHAT_ID - чат в который бот будет отправлять оповещения

## Установка
1. ``` git clone https://github.com/bubblechuk/belstu-notifier.git && cd belstu-notifier ```
2. Делаем .env файл
3. ``` pip install -r requirements.txt ```
4. ```python script.js```
5. Хостим где угодно как угодно
### Пример .env
```
BASE_URL = https://diskstation.belstu.by:5001/webapi
USR = student
PASSWORD = password
BOT_TOKEN = 12345:ABCDEFG
CHAT_ID = -1234567890

```
#### Возможные проблемы
- Если за интервал опроса выложат много лаб, Telegram Bot API может выдат 429 код и тогда ничего не дойдет до целевого чата
- Если файл больше 50 мб, бот вероятно отдаст вам только уведомление и придется качать его вручную
- Если скрипт упадет, то он не засчитает за новые те лабы, которые были выложены в его время простоя
